**CNN Model Collection**
A comprehensive repository showcasing various Convolutional Neural Network (CNN) architectures — from basic CNNs to advanced models like LeNet, AlexNet, VGG, GoogLeNet, ResNet, DenseNet, and MobileNet.  
This project is designed for learning, experimentation, and crop disease detection research using datasets such as **PlantVillage**.
<br>
**About**
CNNs are powerful deep learning models widely used in computer vision. This project provides clean, modular implementations of popular CNN architectures, making it easier for students, researchers, and developers to:
-> Understand CNN concepts through practical code
-> Train and evaluate models on custom datasets
-> Compare performance across different architectures
-> Apply CNNs to real-world problems like crop disease detection
<br>
**Features**
-> Modular codebase (easy to extend and modify)
-> Training and evaluation scripts with metrics (accuracy, precision, recall, F1-score)
-> Jupyter notebooks for step-by-step learning
-> Results logging and visualization
<br>
**Architecture Included**
-> Basic CNN
-> LeNet
-> AlexNet
-> ResNet
-> DenseNet
-> MobileNet
<br>
**Results**
Each model is evaluated on accuracy, precision, recall, and F1-score.
Confusion matrices and performance charts are included github repository with code.
Example (PlantVillage dataset):
ResNet: 95% accuracy
VGG16: 92% accuracy
MobileNet: 90% accuracy
